# Platypus Finance pool contract tags

Returns every unique poolAddress from all LiquidityPool source records in the current published Messari Platypus Avalanche deployment Qmb7S3fSHij3pej9yuXyNsuK2gGv4xmhaBcbfhuWRG7NJy. Source B35cLTayreXTML6fXPTrFNSYx7mKyDuuV51LjVxWwWjp. The schema describes entity id as the asset contract and poolAddress as the actual pool. Asset receipts and underlying token addresses are not emitted. Shared pool references are deduplicated, without age, balance, activity or output limits. Historical pools are included.

The source deployment, protocol identity and pinned hash/number are checked on every page. Address-valued entity IDs have no unique sequential field; all pages use a strictly advancing ID cursor. Unknown addresses, malformed pages and source errors throw; no partial output.
